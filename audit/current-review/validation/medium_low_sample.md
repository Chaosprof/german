# Independent validation — stratified medium/low sample

I independently checked all 183 sampled findings in input order against the current bank rows. I treated `CONFIRM` as confirmation of both the substantive finding and its original severity. `REVISE` preserves a real issue but changes the diagnosis or remedy; `DOWNGRADE` and `UPGRADE` change severity; `REJECT` means the current value is acceptable or the proposed correction is not reliably better. CEFR judgments remain approximate because the project has no cited item-level CEFR authority.
